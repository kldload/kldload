kldloadOS 1.0.2 — AI-Powered Infrastructure
Not the smartest AI in the room.
But it read the manual. So you don’t have to.
What’s new in 1.0.2
• Local AI assistant (early preview) — Ollama + llama3.1:8b + Open WebUI, fully offline after first boot
• 4 AI commands: kai, kai-voice, kai-do, kai-remote — trained on kldload documentation
• Arch Linux support — internet install, rolling release, ZFS via archzfs
• NVIDIA GPU auto-detection — driver checkbox enabled only when GPU present
• AI model gating — models disabled when system doesn’t meet RAM/VRAM requirements
• Live tools — fio, smartctl, nvme-cli, nmap, iperf3, stress-ng, memtest86+
• Boot reliability — EFI boot order fix, mount stacking fix, chroot stability
• Management dashboard — built-in web UI on :9000 for ZFS snapshots, rollback, pool status, and logs. No CLI required.
• USB & hardware — Thunderbolt/USB-C, USB hubs, USB Ethernet dongles, NVMe, SD cards, virtio. Boots from USB-C adapters and docking stations now.
• Recommended: CentOS Stream + Desktop. Other distros should work but are still being tested.
