kldloadOS 1.0.4 — Kubernetes on ZFS
Production Kubernetes from one USB stick.
Golden image → ZFS clone 4 nodes in <100ms → Cilium eBPF → done.
What’s new in 1.0.4
• Kubernetes cluster — kube-cluster bootstrap deploys 1 CP + 3 workers on ZFS instant clones
• Cilium eBPF CNI — replaces kube-proxy entirely, Gateway API, network policies in-kernel
• MetalLB — real LoadBalancer IPs on bare metal (no cloud required)
• Hubble — eBPF-powered network observability (every flow, every DNS query)
• WireGuard backplane — encrypted mesh between all K8s nodes (dual-plane)
• ZFS CSI — persistent volumes backed by ZFS with instant snapshots
• K8s bootstrap checkbox — one install, one reboot → production cluster
• 21-option kube-demo — add/replace nodes, drain, rolling updates, network policy, self-healing
• ZFS Dev Lab — 6-distro dev platform with blue-green deployment + observability
• CentOS + Debian both fully tested — 38-point smoke test pass
• Nodes are cattle — clone in 100ms, replace in 52 seconds, zero downtime
• Select KVM Host + K8s checkbox for full cluster deployment.
