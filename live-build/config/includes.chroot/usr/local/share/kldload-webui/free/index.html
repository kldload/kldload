➕ Install kldload Elsewhere One-shot bootstrap — click to copy
Apple Silicon Mac (M1/M2/M3)
From macOS: install Fedora Asahi Remix, then run this from Asahi to layer kldload
curl -sL https://raw.githubusercontent.com/kldload/kldload-free/main/live-build/config/includes.chroot/usr/local/share/kldload-ansible/playbooks/asahi-convert.yml | sudo tee /tmp/kc.yml > /dev/null && sudo dnf install -y ansible-core git && sudo ansible-playbook /tmp/kc.yml
Prereq: curl https://alx.sh | sh on macOS first, pick Fedora Asahi whole-disk
Any existing Linux host
Layer kldload tools onto a running Debian/Ubuntu/Fedora/Rocky/CentOS system
git clone https://github.com/kldload/kldload-free /tmp/kldload && sudo cp /tmp/kldload/live-build/config/includes.chroot/usr/local/bin/* /usr/local/bin/ && sudo cp -r /tmp/kldload/live-build/config/includes.chroot/usr/local/share/kldload-ansible /usr/local/share/
Fresh bare-metal x86_64
Burn this USB to /dev/sdX on a target machine
sudo umount /dev/sda* 2>/dev/null; sudo wipefs -a /dev/sda && sudo dd if=/path/to/kldload-1.0.4-x86_64.iso of=/dev/sda bs=4M status=progress oflag=direct conv=fsync && sync
aarch64 VM on any Mac (UTM/Parallels)
Build the ARM ISO on this host, then attach in your VM manager
ARCH=aarch64 ./deploy.sh builder-image && ARCH=aarch64 PROFILE=kvm ./deploy.sh build
