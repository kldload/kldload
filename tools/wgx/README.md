# wgx — vendored build of wgxplore (temporary bridge)

wgxplore is its OWN project (`github.com/zxplore/wgxplore`), sister to
zxplore: the WireGuard networks console — declared networks, estate
inventory with handshake health, container attach via the kernel's netns
move, GUI + static TUI from one tree.

This directory is a **verbatim copy** kept only until the upstream repo has
a remote. When it does, `builder/build-iso.sh` switches to the same
tracks-main clone it already uses for zxplore and this directory is
deleted. Do not fix bugs here — fix them upstream and re-sync.
