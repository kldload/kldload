Profile

Determines what packages and tools install. You can switch profiles later — but reinstalling is faster than re-bolting.

core

Core

The minimum: ZFS on root, working bootloader, sshd. No GUI, no kldload tools, no extras.

  • ZFS on root
  • SSH
  • klab / kube-cluster
  • kldload web UI
server

Server

Headless. ZFS + sanoid + WireGuard mesh + eBPF tools + the full kldload tool belt.

  • Everything in Core
  • sanoid · WireGuard · eBPF
  • klab · kube-cluster · kzfs-test
  • GNOME desktop
desktop

Desktop

Server profile + GNOME, NVIDIA drivers, Firefox, container runtime, klab UI in a browser.

  • Everything in Server
  • GNOME · NVIDIA · Firefox
  • podman · klab UI · Open WebUI
  • file pickers · Wayland
