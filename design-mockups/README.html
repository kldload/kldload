kldload — design samples

Four standalone HTML mockups. Open each in a tab and flip — they're real CSS, not pictures, so you can poke at them in DevTools.
Operator console · four directions for the same data
D

Demoscene · painterly atmosphere + micro-rendering

index-demoscene.html
Inspired by demoscene shader stills — deep magenta-rose + dusty teal + warm peach on a purple-black canvas. Slow plasma drift in the background (90s cycle), ghost petals drifting upward, glass panels with traveling sheens, rim lights, breathing accent lines. Triangle sigil brand mark, credit-roll typography (wide letter-spacing all caps). Latest direction. Honors prefers-reduced-motion.
C

Five-color · violet · jade · blue · orange

index-rich.html
Black canvas + five real colors used as surfaces (tinted panel headers, gradient borders, glowing pips), not 3px status bars. Titles use a violet→blue gradient fill, body text is bright with a subtle dark offset for crispness, four tonal surface steps for depth.
A

Linear × k9s · single accent

index.html
Polished operator console with five tabs: Dashboard, Install progress, ZFS pools, KVM & klab, Logs. Sans chrome with monospace data, hairline borders, single purple accent, status as left-border bars. Vanilla-pro.
B

k9s × tmux · pure terminal

index-terminal.html
Mono everywhere including chrome. 12px base, dense rows, right-side info pane, footer keybinding hints (? : /). Looks like a TUI in a browser. Could co-exist with C as a "compact" mode for power-user views.
Marketing site · sample homepage
C

kldload.com — homepage v2

website-home.html
Hero with the same tokens, distro grid (8 cards), feature grid (6), code-block install demo, footer. Same purple accent, same hairline borders, same mono-for-numbers discipline as the operator console — so the marketing site and the live product feel like one product.
Live installer · what users see during install
D

Install wizard — distro & profile

webui-installer.html
Step 4/8 of the installer. Left rail = step list + live summary, right pane = current step. Six distro tiles, three profile tiles, sticky action bar with running summary. Replaces the current single-page-form installer with something that feels designed.
All four share the same tokens — drop them into one CSS file and ship.

--accent #7c5cff · --bg #0a0a0c · --surface #141417 · --border #26262d · --ok #10b981 · --warn #f59e0b · --err #ef4444

Switching the accent to a different brand color (say, the current green) is a one-line change. Direction A is the recommended starting point — Direction B is for terminal-power views (logs, kubectl-style lists) once A is shipped.
