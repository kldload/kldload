# nginx — single TLS reverse proxy on :8443 fronting webui/grafana/k9s/
# headlamp/sessions with HTTP/2. Replaces the hand-rolled Python
# kldload-proxy from 1.0.5; HTTP/2 multiplexing eliminates the parallel-
# connection cert-trust flicker on Grafana and the session-terminal
# drop-in pattern needs real nginx -s reload semantics that stdlib can't
# give us. Plus: enterprise path needs auth_request + mTLS + OIDC
# forward-auth hooks that only nginx provides cleanly.
nginx

# noVNC + websockify — graphical "View" console for VMs in the kldload
# webui. The webui's _vm_display_open spawns websockify pointing at the
# VM's qemu VNC port; novnc's HTML5 client renders the framebuffer in
# the user's browser via the same /s/<id>/ nginx drop-in pattern as the
# SSH terminal sessions. Together with vm-ssh (terminal) they're the
# "SSH / View" pair on every running-VM row in the UI.
novnc
python3-websockify
