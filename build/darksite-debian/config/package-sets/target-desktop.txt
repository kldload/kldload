# Display manager: LightDM (NOT gdm3). GDM 48 on Debian Trixie has a

# "Unit name gnome-session-(null)@gnome.target is not valid" and GDM

# all installed. LightDM bypasses systemd-managed session units, runs

# PAM modules — Debian splits these out from the parent packages.
# libpam-gnome-keyring provides /usr/lib/.../security/pam_gnome_keyring.so.
# libpam-systemd is required by user-session/cgroup integration.
# Without these, GDM autologin warns "PAM unable to dlopen" and session
# worker gets confused — fixing the underlying GDM 48 bug is upstream's
# problem, but we install these regardless so the future GDM-fixed
# Debian release works without re-darksiting.
libpam-gnome-keyring
libpam-systemd
# xdg-desktop-portal — Wayland portal backends GNOME 46+ needs to
# launch the user shell (file pickers, screenshots, screen sharing).
xdg-desktop-portal
xdg-desktop-portal-gnome
xdg-desktop-portal-gtk
# dbus-x11 provides /usr/bin/dbus-launch which gnome-session calls to
# bootstrap a session DBus when not under systemd-managed login.
# Without it, gnome-session-binary errors "Failed to execute child
# process dbus-launch (No such file or directory)" → session falls
# back to non-systemd path which then fails to upload environment to
# DBus → user logs in at lightdm but gets bounced back to greeter.
dbus-x11
firefox-esr
# Codecs and VA-API. .105 2026-08-28 had gstreamer avdec_* at ZERO -- no H.264,
# no H.265, no AAC -- and no VA-API driver at all, so video neither decoded nor
# accelerated. gstreamer1.0-libav is the ffmpeg bridge; it is NOT plugins-bad
# and does not drag in the libfluidsynth3 -> sf3-soundfont-gm chain that the
# header comment above warns about (verified in a trixie container).
gstreamer1.0-libav

# audit, which is a diagnostic that lies in the alarming direction. (2026-08-28)
gstreamer1.0-tools
