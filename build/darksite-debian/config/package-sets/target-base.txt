# Declared, not inherited. firmware-amd-graphics reaches the media today only
# as another package's dependency -- profiles.sh asks for it by name, so the
# day that dependency moves, the request resolves to nothing and every Radeon
# installs with no firmware. amdgpu does not initialise without its blobs, so
# that is a black screen, not a slow desktop. Same trap as the Fedora side
# (2026-08-28); firmware-misc-nonfree above carries the Intel GPU blobs.
firmware-amd-graphics
# CPU microcode. Nothing else pulls these, and without them the machine runs
# with no microcode updates on any CPU -- .105 2026-08-28 had both amd-ucode
# and intel-ucode directories EMPTY. Both listed; the kernel loads the one
# that matches and ignores the other.
amd64-microcode
intel-microcode
# The per-vendor firmware split. firmware-linux-nonfree Depends only on
# firmware-misc-nonfree and firmware-amd-graphics; everything here is

# it arrived. .105 2026-08-28: brcm 1 file, mediatek/cirrus/qcom/i915 all zero.
